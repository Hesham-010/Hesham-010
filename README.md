Backend developer with hands-on experience delivering production systems used by real customers.
I work mainly with **Node.js (NestJS / Express)**, **TypeScript** and **Laravel**, designing

- ⚡ Comfortable with **microservices** (Kafka), **Redis** caching, **Elasticsearch** and **Docker**-based environments
- 🔐 Strong focus on authentication/authorization, data modelling and query optimization
- 🧪 Work with Agile teams, Git-based workflows, Postman/Swagger documentation and TDD where it pays off
